# Zasady projektowe – Elektron

Kopiujemy i adaptujemy zasady z ex-polonez:

- Maintainability First
- Circular DIY + Low-Cost
- Metal tylko dla sił i bezpieczeństwa
- Druk 3D + spawanie + upcycling wszędzie indziej
- Modularne kasety baterii
- Service Box / łatwy dostęp
- Pełna otwartość dokumentacji

Dodatkowe dla quada:
- Wytrzymałość na użytkowanie terenowe / użytkowe
- Możliwość pracy z obniżoną liczbą kaset baterii
- Prosta geometria ramy możliwa do spawania przez osobę z podstawowymi umiejętnościami
