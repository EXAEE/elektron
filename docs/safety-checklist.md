# Safety Checklist – Elektron

## Przed pierwszym uruchomieniem

- [ ] Izolacja HV zmierzona i zapisana
- [ ] Interlocki na złączach baterii działają
- [ ] Wyłącznik awaryjny odcina zasilanie
- [ ] Hamulce sprawne (przód + tył)
- [ ] Kierownica i układ kierowniczy bez luzów
- [ ] Wszystkie śruby krytyczne dokręcone odpowiednim momentem
- [ ] Baterie zabezpieczone mechanicznie i nie ruszają się w kasetach
- [ ] Przewody HV nie ocierają o ostre krawędzie
- [ ] Test na podnośniku / stojaku przed jazdą

## Regularny serwis

- [ ] Stan opon i ciśnienie
- [ ] Luz łańcucha / wału
- [ ] Temperatury baterii i silnika po jeździe
- [ ] Stan izolacji (okresowo)
