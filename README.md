# Elektron

**Polski open-source elektryczny quad**

Zasady: Maintainability First + Circular DIY + Low-Cost + upcycling + max druk 3D / spawanie.

## Wizja w skrócie

Prosty, naprawialny, tani w budowie quad. Rama spawana ze złomu, baterie kasetowe, napęd z upcyclingu, jak najwięcej elementów drukowanych.
